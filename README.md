# SkillSync — Job Skills Gap Analyzer

Analyze the gap between your current skills and your target job role.

## Live Demo
https://skillsync-model.streamlit.app/

## How it works
- Enter your skills (comma separated)
- Select your target job title
- Get a match score and list of missing skills

## Tech Stack
- Python, Scikit-learn, TF-IDF Vectorizer, Logistic Regression, Streamlit

## Dataset
Job descriptions dataset from Kaggle (500 rows)
